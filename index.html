I'm the developer behind Laymon Games, a solo indie studio focused on distinctive games and creative digital projects. I work across programming, 2D and 3D art, sound, music, editing, and presentation so the whole project can keep one consistent direction.

I like building complete things — a playable game, a finished track, or an edited trailer — and using new tools when they genuinely improve the work.

04 · Process

Idea. Prototype. Create. Polish.

  1. 01Idea

    Find the core idea and what makes it interesting enough to build.

  2. 02Prototype

    Build the smallest playable or visible version to see if it works.

  3. 03Create

    Develop gameplay, art, audio, environments, and the systems around them.

  4. 04Polish

    Test, refine, remove what's weak, and improve the presentation.

One person, moving across the whole pipeline.
