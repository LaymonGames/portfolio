I'm the person behind Laymon Games, a solo indie developer focused on making games, creative digital projects, and editing videos. I work across programming, 2D and 3D art, sound, music, editing, and presentation so the whole project can keep one consistent direction.

I like building games, from brainstorming ideas to finishing the project, and using new tools when they genuinely improve the workflow.

Process

Idea. Prototype. Create. Polish.

  1. 01Idea

    brainstorming an interesting idea, then upgrading it.

  2. 02Prototype
